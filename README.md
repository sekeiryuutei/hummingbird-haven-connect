# Finca Alejandría · El Paraíso de los Colibríes

Plataforma web y aplicación progresiva (PWA) para el apadrinamiento de colibríes, seguimiento comunitario y transparencia de conservación en el bosque de niebla del Km 18, Cali.

## Características

- **Catálogo de especies**: Exploración de colibríes protegidos, estado de salud, conservación y cupos disponibles.
- **Apadrinamiento interactivo**: Selección de aportes mensuales y pasarela de demostración con persistencia local.
- **Comunidad de padrinos**: Foro por especie con carga de fotografías optimizadas, comentarios e interacciones.
- **Transparencia e impacto**: Métricas en tiempo real del recaudo, distribución de recursos y registro detallado de inversiones.
- **Portal de administración**: Gestión local de especies, cupos, estados de salud y registro de nuevos gastos de conservación.

## Desarrollo local

Requisitos: Node.js 20+ y npm.

```sh
npm install
npm run dev
```

## Scripts disponibles

- `npm run dev` — Inicia el servidor de desarrollo.
- `npm run build` — Genera la versión optimizada para producción.
- `npm run preview` — Previsualiza la compilación de producción localmente.
- `npm run test` — Ejecuta las pruebas automatizadas con Vitest.
